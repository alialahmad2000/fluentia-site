# Image prompts — direction `ink` (حبر وجمر)

Status: fal.ai was locked (`User is locked. Reason: TOP_UP`) on every job, so **no new images were generated and fal spend is $0**. The shipped images are crops and re-grades of the four shoot-out frames (`scratchpad/fal/out/shoot/ink/nano-*.jpg`, tone reference `nano-0.jpg`), so several plates repeat the same room. Replace them with the prompts below.

## Slots and how to drop them in
Pages read every image through `<Art dir="ink" name="...">`, so replacing a slot = running `tools/img.mjs <src> public/images/journal/ink <name> wide=FX,FY tall=FX,FY og= story= post=` at the exact name (outputs `-w800/1280/1920.webp`, `-t600/900/1200.webp`, optional `-og.jpg`, `-story.webp`, `-post.webp`). Nothing in the code needs to change.

| name | aspect | used for |
|---|---|---|
| `cover` | 16:9 + 4:5 (`wide`/`tall`) | home cover, og image |
| `plate-<slug>` x6 | 16:9 + 4:5 | article hero + home cards (slugs: first-ten-minutes, understand-but-cant-speak, words-that-betrayed-us, accent-is-not-the-problem, fear-of-mistakes, adults-learn-differently) |
| `scene-door` | 3:2 | chapter break in first-ten-minutes |
| `scene-table` | 3:2 | chapter break in fear-of-mistakes, home quote band |
| `quote-story`, `quote-post` | 9:16, 4:5 | background of shared quote cards (needs a calm dark lower half for text) |

## Style recipe (append to every prompt)
Cinematic night photograph on 35mm Kodak Vision3 500T cinema film, heavy visible film grain, chiaroscuro, deep warm ink-black shadows (near #0E0B09) that swallow most of the frame, exactly ONE ember-orange practical light source inside the scene (vermilion #E8542C to amber #FF7A45) as the only light, soft halation around the light, shallow depth of field, moody editorial magazine photography. Strictly a black-brown and ember-orange palette: no blue, no teal, no white, no cool tones. Large calm dark negative space on one side. Absolutely no text, letters, numbers, signage, logos, watermarks or readable screens. No faces, no hands.
